# 我的 Skills 仓库

用户说的"我的仓库"或"我的 Skills 仓库"指 https://github.com/PosvdM/Skills 。安装和更新规则写在线上的安装说明里，每次都读最新版本，不要凭记忆操作：

https://raw.githubusercontent.com/PosvdM/Skills/main/docs/install.md

先读这个文件的全文，再按用户的要求执行：

- **点名安装**：用户说出一个或几个 Skill 的名字，如"去我仓库装上 xxx"，按安装说明中的“点名安装”一节执行。
- **全量安装或更新**：用户没有点名，如"更新我仓库的 skills"，按安装说明的完整步骤执行。

用户装 Skill 是为了接着做某个任务时（如"我要做个 PPT，去我仓库装上 xxx"），装好后先读取新 Skill 的 `SKILL.md` 全文，再继续任务。有的 Agent 不会在会话中途加载新装的 Skill，直接读文件不受影响。
