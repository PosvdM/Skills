# 我的 Skills 仓库

用户说的"我的仓库"或"我的 Skills 仓库"指 https://github.com/PosvdM/Skills 。安装和更新由仓库里的同步脚本完成，做法写在线上的安装说明里。每次先读最新版本的全文，不要凭记忆运行命令：

https://raw.githubusercontent.com/PosvdM/Skills/main/docs/install.md

按安装说明开头的对照表选择做法：点了名就是点名安装，没点名就是日常更新，新装了 Agent、换了机器或用户要求完整检查时是完整安装，只问有没有更新时只检查。

用户装 Skill 是为了接着做某个任务时（如"我要做个 PPT，去我仓库装上 xxx"），装好后先读取新 Skill 的 `SKILL.md` 全文，再继续任务。有的 Agent 不会在会话中途加载新装的 Skill，直接读文件不受影响。
